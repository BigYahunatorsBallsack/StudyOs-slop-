# StudyOS

Persönlicher, offlinefähiger Studienplaner (PWA). Quellcode, Doku und Tests liegen in [`quellcode/`](quellcode/README.md), Änderungen in [`quellcode/CHANGELOG.md`](quellcode/CHANGELOG.md).

Die App wird bei jedem Push auf `main` von GitHub Actions geprüft, gebaut und auf GitHub Pages veröffentlicht (Settings → Pages → Source: „GitHub Actions“).
