# Lernkarten

## Diskrete Strukturen (IN0015, WS 2026/27) – Stoff bis Folie 113

`diskrete-strukturen-in0015.csv`: 322 Karten, Quelle: die acht Lernskripte.

**Import:** Lernen → oben das Modul wählen → „CSV-Import und -Export“ → **CSV importieren**.

**Tags (Filter „Alle Tags“):**

| Tag | Inhalt |
|---|---|
| `1-logik-und-beweise` … `5-relationen` | Überthema |
| `1.1-…`, `2.4-…` usw. | Unterthema |
| `x.0-fachbegriffe-…` / `fachbegriffe` | Fachbegriffe und Symbole (Begriff → Bedeutung, Symbol → Name) |
| `prüfungsfalle` | typische Fehler und Verwechslungen |

Die Karten werden aus `diskrete-strukturen-in0015.py` erzeugt; für Änderungen das Skript bearbeiten und neu ausführen.
